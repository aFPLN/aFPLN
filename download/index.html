Questions

Do I ever need to download it again?

No. FPLN checks for a newer version every time it opens and while it runs. When one is ready you'll see “Update ready · Restart now.”

Will the alarm work with the screen off?

Yes, while FPLN is open. On a laptop, keep it plugged in. The Windows download includes “FPLN keep awake”, which stops Windows from sleeping while plugged in (and an undo file). For extra safety, Wake up › Back up alarms to my phone.

Where is my data, and who can see it?

Only on the device you use, inside the browser that runs FPLN. Nothing goes to a server, and no one else can see it. More › Backup moves it to a new computer.

The Install button didn't do anything.

FPLN may already be installed: look for it in your Start menu or taskbar. Otherwise, in Edge or Chrome open the ⋯ menu › Apps › Install this site as an app. Firefox can't install apps; use Edge or Chrome, or just use FPLN in the browser.

How do I uninstall it?

Open FPLN, click ⋯ at the top right › Uninstall. On a phone, press and hold the icon › Remove.

Is this an official USMA app?

No. FPLN is a cadet project in beta, not an official USMA or U.S. Army product. Send feedback with the speech-bubble button in the app.
