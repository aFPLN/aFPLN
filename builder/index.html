Publish your changes

  1. Copy your settings.

  2. Open the settings file on GitHub (sign in if asked).

    Open site.json on GitHub ↗

  3. Click in the file, press Ctrl+A then Ctrl+V. Click Commit changes…, then Commit changes.

GitHub checks it (plain text and colors only, no links or personal info) and puts it live in about a minute. Refresh the install page to see it.
