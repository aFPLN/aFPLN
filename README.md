# FPLN · Flight Plan (Beta 1, 0.8.1)

A planner for USMA cadets: your day, tasks, OPORDs, Eric the assistant and a post map with hours.

**Open it:** https://afpln.github.io/aFPLN/
In Edge or Chrome, use **Install** (the banner in the app, or ⋯ › Apps › Install this site as an app) for a taskbar icon and offline use.
Updates arrive automatically the next time FPLN opens.

**Privacy:** everything a cadet enters stays in their own browser on their own device. Nothing is uploaded.
Keep CUI (FRAGORDs, rosters, other cadets' personal information) out of FPLN.

Map data © OpenStreetMap contributors, available under the Open Database License (https://www.openstreetmap.org/copyright).
Hours come from westpoint.edu, keller.tricare.mil, usps.com, shopmyexchange.com, commissaries.com, history.army.mil, ikehall.com and usma.libcal.com.
This is a cadet project, not an official U.S. Military Academy or U.S. Army product.
